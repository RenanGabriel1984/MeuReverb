🚀 Deploy no ▲ Vercel

Guia completo para publicar seu app Meu Reverb

📦 Opção A: Upload Direto

⭐ MAIS FÁCIL

Sem precisar de GitHub. Ideal se você quer publicar rápido!

1
Acesse o Vercel
Vá para vercel.com e faça login na sua conta
2
Clique em "Add New..." → "Project"
No dashboard do Vercel, clique no botão azul no canto superior direito
3
Escolha "Import Third-Party Git Repository" ou role para baixo
Procure a opção "Deploy from a template" ou "Upload" na parte inferior da página
4
Arraste a pasta dist
Se estiver usando a opção de upload direto, arraste a pasta dist gerada pelo build
5
Aguarde o deploy
Em alguns segundos seu app estará no ar! Você receberá um link como:
meu-reverb-abc123.vercel.app
💡 Dica: Você pode personalizar o nome do domínio nas configurações do projeto para algo como meu-reverb.vercel.app
ou

🐙 Opção B: Via GitHub

RECOMENDADO

Mais profissional. Deploys automáticos a cada alteração no código!

1
Crie um repositório no GitHub
Acesse github.com/new e crie um novo repositório (ex: meu-reverb)
2
Envie o projeto para o GitHub
No terminal, dentro da pasta do projeto, execute os comandos abaixo:
# Inicializa o git
git init
# Adiciona todos os arquivos
git add .
# Faz o primeiro commit
git commit -m "Primeiro commit"
# Define a branch principal
git branch -M main
# Conecta ao seu repositório
git remote add origin https://github.com/SEU-USUARIO/meu-reverb.git
# Envia para o GitHub
git push -u origin main
3
Conecte o Vercel ao GitHub
No Vercel, clique em "Add New..." → "Project" e selecione o repositório meu-reverb
4
Configure o Framework
O Vercel vai detectar automaticamente que é um projeto Vite. Confirme as configurações:
  • Framework Preset: Vite
  • Build Command: npm run build
  • Output Directory: dist
5
Clique em "Deploy"
Aguarde alguns segundos e seu app estará no ar! 🎉
✨ Vantagem: A cada alteração que você fizer no código e enviar para o GitHub, o Vercel faz o deploy automaticamente!

📱 Após o Deploy

Agora que seu app está no ar, instale no celular!

📲
Android (Chrome)
1. Abra o link no Chrome
2. Toque nos 3 pontos (⋮)
3. Selecione "Instalar app"
4. Confirme em "Instalar"
🍎
iPhone (Safari)
1. Abra o link no Safari
2. Toque no botão Compartilhar (↑)
3. Selecione "Adicionar à Tela de Início"
4. Toque em "Adicionar"
⚠️ Importante: No iPhone, use apenas o Safari! Outros navegadores não suportam PWA no iOS.

✅ Checklist Final

  • Conta criada no Vercel
  • Projeto enviado para o GitHub (ou upload direto)
  • Deploy realizado com sucesso
  • Link funcionando no navegador
  • App instalado no celular
  • Funcionando offline!

🎸 Agora é só usar e aproveitar seus presets!
