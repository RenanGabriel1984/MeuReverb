🎸 Como Usar o Meu Reverb

Guia completo para usar o app no seu celular

🌐 Opção 1: Hospedar Online (Recomendado)

A maneira mais fácil é hospedar o app em um serviço gratuito. Assim você pode acessar de qualquer lugar!

🚀 Netlify (Mais Fácil)

1
Acesse netlify.com
Crie uma conta gratuita
2
Arraste a pasta dist
Arraste a pasta dist para a área de deploy do Netlify
3
Pronto!
Você receberá um link como meu-reverb.netlify.app

⚡ Vercel

1
Acesse vercel.com
Crie uma conta gratuita com GitHub
2
Suba o projeto para o GitHub
Crie um repositório e faça push do código
3
Conecte no Vercel
Importe o repositório e o Vercel faz o deploy automaticamente

🐙 GitHub Pages

1
Crie um repositório no GitHub
Suba o conteúdo da pasta dist
2
Ative o GitHub Pages
Vá em Settings → Pages → Source: main branch
3
Acesse o link
Seu app estará em seu-usuario.github.io/nome-repo

🏠 Opção 2: Rede Local (Sem Internet)

Use o app apenas na sua rede WiFi, sem precisar de hospedagem externa.

💻 No Computador

1
Abra o terminal na pasta do projeto
Navegue até a pasta onde está o projeto
2
Instale um servidor HTTP
npm install -g serve
3
Sirva a pasta dist
serve dist -l 3000
4
Descubra seu IP local
Windows: ipconfig
Mac/Linux: ifconfig ou ip addr
5
Acesse no celular
Abra no celular: http://192.168.X.X:3000 (use seu IP)
💡 Dica Importante
O computador e o celular devem estar na mesma rede WiFi. O IP geralmente começa com 192.168.

📱 Instalando como App no Celular

Após acessar o app pelo link, instale como aplicativo para usar offline!

📲 Android (Chrome)

1
Abra o app no Chrome
Acesse o link do app no navegador Chrome
2
Toque no menu (⋮)
Três pontos no canto superior direito
3
Selecione "Instalar app"
Ou "Adicionar à tela inicial"
4
Confirme
Toque em "Instalar" e o app aparecerá na tela inicial!

🍎 iPhone (Safari)

1
Abra o app no Safari
Use o Safari (não funciona em outros navegadores no iOS)
2
Toque no botão Compartilhar
Ícone de quadrado com seta para cima (↑) na parte inferior
3
Role para baixo
Procure "Adicionar à Tela de Início"
4
Toque em "Adicionar"
Confirme no canto superior direito
✨ Vantagens de Instalar
• Funciona offline após o primeiro acesso
• Abre como app nativo (tela cheia)
• Ícone na tela inicial
• Acesso rápido sem abrir o navegador

🎛️ Usando o App

➕
Toque no botão + para criar preset
🎸
Veja o pedal com os knobs nas posições
✏️
Edite presets existentes
🗑️
Delete presets que não usa mais
🔍
Busque por nome ou tipo
❓
Toque em ? para ver ajuda
🎯 Dica de Uso
Use nomes descritivos como "Ocean Eyes - Worship" ou "Refrão - Hall" para encontrar seus presets rapidamente durante os ensaios!

🚀 Resumo Rápido

1. Hospede o app (Netlify é o mais fácil)

2. Acesse o link no celular

3. Instale como app (Android/iPhone)

4. Use offline sempre que precisar!
